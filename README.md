# Noir — Шпионские игры

Онлайн-версия режима **Шпионские игры** из настольной игры «Нуар».

Стек: **PHP Symfony 7** (игровая логика + HTTP) · **WebSocket (Ratchet)** · **Vue 3**.

## Что умеет

- Выбор режима «Шпионские игры»
- Список лобби со статусом (`Сбор игроков` / `Игра идёт`)
- Вход только на стадии сбора; после старта хостом подключиться нельзя
- Игра: поле 5×5 / 6×6 / 7×7, действия **Поймать**, **Допросить**, **Сдвинуть**, **Обновить**
- Карты схематичные (только имя), без иллюстраций
- Куча-мала (3–5) и команды (6 / 8 / 9)

## Быстрый старт (Docker)

Нужен запущенный **Docker Desktop**.

```bash
docker compose up --build
```

- Фронт (Vite): http://localhost:5173  
- Symfony HTTP: http://localhost:8000  
- WebSocket: ws://localhost:8081  

В dev удобнее открывать **5173** (`VITE_WS_URL` уже указывает на 8081).

## Локально без Docker

Нужны PHP 8.2+, Composer, Node 20+.

```bash
# Backend
cd backend
composer install
php -S 0.0.0.0:8000 -t public

# WebSocket (второй терминал)
cd backend
php bin/console app:websocket --port=8081

# Frontend (третий терминал)
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173 — для продакшен-сборки:

```bash
cd frontend
npm run build
```

Тогда UI отдаёт Symfony с http://localhost:8000

## Локальный тест интерфейса

Достаточно Node.js 20+. PHP, Docker, Telegram и другие игроки для этого режима не нужны.

```bash
cd frontend
npm ci
npm run dev:ui
```

Откройте [http://127.0.0.1:5174](http://127.0.0.1:5174). Введите имя агента и создайте лобби, чтобы начать тестовую партию. Свободные места займут боты. Выбор числа игроков позволяет проверить поля 5×5, 6×6 и 7×7, а действия дают возможность проверить состояние клеток, журнал и экран победы. Чтобы увидеть экран ожидания гостя, войдите в готовое «Тестовое лобби».

Ходы ботов пропускаются, а действия используют упрощённые тестовые ответы. Перезагрузка страницы сбрасывает партию. Для проверки реальных правил и многопользовательской игры используйте обычный `npm run dev` с запущенным WebSocket-сервером.

## Запуск в Telegram

NOIR можно открыть внутри Telegram как основное мини-приложение бота. Игроки по-прежнему выбирают имя агента при первом входе.

1. Направьте DNS-запись домена на сервер с Docker и откройте на нём TCP-порты 80 и 443. В `.env.local` рядом с файлом Compose укажите `NOIR_DOMAIN=play.example.com`, подставив свой домен без `https://`, и `NOIR_APP_SECRET` со случайным значением, которое можно получить командой `openssl rand -hex 32`.
2. Запустите на сервере `docker compose --env-file .env.local -p noir-telegram -f docker-compose.telegram.yml up -d --build`. Caddy выпустит HTTPS-сертификат и направит `wss://play.example.com/ws` на игровой сервер. Проверьте, что HTTPS-страница открывается и в списке лобби появляется статус подключения.
3. Создайте бота через [@BotFather](https://t.me/BotFather) или выберите существующего. В `/mybots` откройте **Bot Settings → Configure Mini App → Enable Mini App** и укажите `https://play.example.com/`.
4. Откройте игру кнопкой в профиле бота или по ссылке `https://t.me/ИМЯ_БОТА?startapp`. Чтобы добавить кнопку «Играть» и в чате бота, задайте тот же URL через `/setmenubutton`.

Если у сайта уже настроен HTTPS, используйте его адрес и добавьте в действующий прокси маршрут `/ws` с поддержкой WebSocket Upgrade до Ratchet на порту 8081. Сборка фронтенда продолжит обращаться к игровому серверу по тому же домену. [Документация Telegram Mini Apps](https://core.telegram.org/bots/webapps#launching-the-main-mini-app)

## Как играть

1. Укажите имя агента  
2. Создайте лобби (3–6, 8 или 9 мест) или войдите в существующее со статусом «Сбор»  
3. Хост нажимает **Начать игру**, когда набралось допустимое число игроков  
4. В свой ход: выберите соседнюю клетку → Поймать / Допросить, либо сдвиньте ряд / обновите поле  
5. Ваша тайная личность подсвечена на поле; трофеи копятся до победы  

## Протокол WebSocket (кратко)

Клиент → сервер:

| type | назначение |
|------|------------|
| `hello` | `{ playerId, playerName }` |
| `lobby.list` | список лобби |
| `lobby.create` | `{ name, maxPlayers, playerName }` |
| `lobby.join` | `{ lobbyId, playerName }` |
| `lobby.leave` | выйти |
| `lobby.start` | хост начинает |
| `game.action` | `{ action, ... }` — catch / interrogate / shift / update |

## Арт-паки

При создании лобби выбирается набор портретов:

| id | формат | описание |
|----|--------|----------|
| `ink-minimal` | SVG ×50 | Чернильный минимализм |
| `brush-flat` | PNG ×50 | Плоская кисть (AI) |

Новый набор: папка `frontend/public/art-packs/{id}/` + запись в `ArtPackCatalog`.

## Звук

События лобби и партии озвучиваются у **всех** клиентов (Web Audio). Кнопка «звук» в шапке глушит/включает.
